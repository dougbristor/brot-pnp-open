# Axis control point, n = 2

With c = (0,0,0), B(x,0,0) = (x², 0, 0). So (3/10,0,0) -> (9/100,0,0) -> (81/10000,0,0) = A exactly.
This is one level-2 point of the backward tree from A = (81/10000, 0, 0), on the real axis.
It is a rational instance of the axis control in QUESTION.md (there A = (0.3,0,0); that A has irrational preimages at n >= 2, so it cannot be given as an exact chain).
It claims nothing beyond this one point.
